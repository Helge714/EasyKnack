**Experimental Linux test build — not a stable release.**

This complete package includes the clearer oscilloscope traces, opaque Linux
documentation dialogs and corrected native compiler diagnostics. It also adds an
optional graphics test to investigate window recreation when moving between
monitors. That monitor issue is **not yet confirmed fixed**.

Earlier audio routing, capture and virtual MIDI checks passed on an EndeavourOS
computer. This version was cross-built on Windows; its Linux executables still
need target testing. Local Java/GPU and package checks do not replace that test.

## Download and start

1. Download **`EasyKnack-0.4.0-SNAPSHOT-linux-x86_64-test-3.tar.gz`** below.
2. Extract the complete archive into a **fresh, writable folder**.
3. Open a terminal in the extracted `EasyKnack` folder and run `./Check-Linux.sh`.
   The first compiler test can take several minutes.
4. Close any existing EasyKnack instance, run `./Start-Graphics-Test.sh`, move the window between monitors, resize it,
   open and scroll documentation, then close EasyKnack normally.

Please return **`linux-diagnostics.txt`** and **`graphics-diagnostics-*.txt`**.
The optional comparison command `./Start-Graphics-Test.sh --translucent-dialogs`
restores the earlier transparent dialog path for that run only. Report whether
documentation flickers in one mode or both.

For ordinary use, `./Start-EasyKnack.sh` starts without the graphics trace.
This is a **portable archive, not an installer**. The `.tar.gz` is the only
required download; sources and checksums are separate inspection materials.
Keep copies of important projects before saving them with this development build.

## Included

- Sixteen example projects with German and English instructions.
- Bundled Java JDK and C++ compiler for Formula, Bake and source plugins.
- Linux audio devices, system/application capture, hardware MIDI and MP3 recording.
- Diagnostic tests and optional process/window/OpenGL/display-scale logging.
- Matching sources, build materials and license notices, also offered separately.

## Requirements

Linux **x86_64 (Intel/AMD)** with glibc 2.28 or newer, X11/XWayland and OpenGL 3.
ARM and Alpine/musl are not supported. Desktop audio requires PulseAudio or
PipeWire-Pulse; hardware MIDI requires ALSA. Java and compiler are bundled.
Choose your Linux audio/MIDI devices after opening a project from another system.

## Help test

Besides the monitor/documentation test, try playback, recording, MIDI/Learn,
Formula/Bake, capture and the oscilloscope. Report your distribution, display
scaling, audio/GPU hardware and steps to reproduce problems. Logs stay local;
nothing is sent automatically.
