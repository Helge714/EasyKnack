EasyKnack 0.3.1 fixes connection editing and Java setup, improves German translations and includes a refreshed example library.

## Improvements

- Select and delete connections reliably in all themes, with Undo support.
- Install Java through Setup without conflicting with the EasyKnack installation.
- Use sixteen bundled examples covering basics, buffers, MIDI, Instance Groups, Spectral Groups, Formula Groups and feedback. Graphs open centered and arranged for easier reading.
- Enjoy more complete German labels and correctly translated node menus when changing languages.

## Download and install

Download **[EasyKnack-Setup-0.3.1-x64.exe](https://github.com/Helge714/EasyKnack/releases/download/v0.3.1/EasyKnack-Setup-0.3.1-x64.exe)** and follow the setup instructions. This is the only download needed for installation; examples are included.

Requires **64-bit Windows** and a **64-bit Java 25 JDK**. Setup checks Java and helps install it if needed. The installer is unsigned, so Windows may ask you to allow it explicitly.

Existing 0.3.0 projects remain compatible. Keep a backup of important projects before updating. Linux and macOS builds remain separate experimental downloads.

The other downloads provide source code and checksums.
