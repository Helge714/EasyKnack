EasyKnack lets you build synthesizers, audio effects and analysis tools by connecting nodes visually. German and English help is included in the application.

## Download and install

1. Download **[EasyKnack-Setup-0.1.0-x64.exe](https://github.com/Helge97/EasyKnack/releases/download/v0.1.0/EasyKnack-Setup-0.1.0-x64.exe)**.
2. Run the downloaded file and follow the setup instructions.

Requires **64-bit Windows** and a **64-bit Java 25 JDK**. Setup checks Java and helps you set it up if it is missing.

**The setup EXE is the only download needed for installation.** The other files contain source code and optional technical information.
