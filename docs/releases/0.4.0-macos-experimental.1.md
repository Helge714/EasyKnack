# EasyKnack for Mac — experimental test 1

This is the first experimental Mac test version, **not a stable release**. It
requires macOS 14.2 or newer. Automated tests passed on macOS 15 for both Mac
architectures; real audio hardware, capture permissions and everyday operation
still need testing.

## Download and install

- **Apple Silicon (M1 or newer):** download the `macos-arm64` DMG.
- **Intel Mac:** download the `macos-x86_64` DMG.

Open the DMG and drag EasyKnack to Applications. Java and sixteen examples with
German/English instructions are included. Select your Mac's audio/MIDI devices
after opening a project created on Windows or Linux.

The test app is ad-hoc signed, **not Apple-notarized**. macOS may block its first
launch. Use Apple's per-app approval in Privacy & Security if offered; do not
disable Gatekeeper globally. This build has no automatic update mechanism.

Native Formula compilation, Bake and source plugins additionally require Apple's
Command Line Tools or Xcode. Ordinary formulas retain their interpreter fallback.
Microphone and system/application capture require the corresponding permissions.

## Help test

Please try playback, recording, device switching, MIDI/Learn, Formula/Bake,
Finder file opening and display scaling. Report your Mac model, macOS version,
audio device and steps to reproduce problems. `Check-Mac.command` inside the DMG
can collect diagnostics under `~/Library/Logs/EasyKnack`.

## Licenses and sources

Licenses and matching sources/build materials are included in the app. The
architecture-specific `license-materials.zip` downloads provide those materials
separately; they are **not required to run EasyKnack**. Keep them available when
redistributing the binaries. The accompanying JSON files record the technical
distribution checks. This review is not a legal clearance certificate.

The stable Windows release remains unchanged.
