**Experimental macOS test build — not a stable release.**

This early version is for trying EasyKnack on a Mac and reporting problems.
Automated build, audio-engine, compiler, graphics and package checks passed on
macOS 15 for Apple Silicon and Intel. Real audio hardware, capture permissions
and everyday operation still need testing.

## Download and start

1. Download the **`macos-arm64` DMG for Apple Silicon (M1 or newer)** or the
   **`macos-x86_64` DMG for Intel Macs** below.
2. Open the DMG and drag EasyKnack to Applications.
3. Launch EasyKnack and select your Mac's audio/MIDI devices.

The app is ad-hoc signed, **not Apple-notarized**. macOS may block its first
launch. Use the per-app approval in Privacy & Security if offered; do not disable
Gatekeeper globally.

The matching DMG is the only required download. Source archives and review files
are for redistribution and inspection; checksums are optional integrity checks.
Keep copies of important projects before saving them with this development build.

## Included

- Sixteen example projects with German and English instructions.
- Bundled Java JDK; no separate Java installation is needed.
- macOS implementations for multiple audio devices, system/application capture,
  hardware MIDI and MP3 recording.
- License notices and matching source/build materials.

## Requirements

macOS **14.2 or newer**, Apple Silicon or Intel, and working OpenGL. Automated
testing used macOS 15; the minimum supported version still needs testing.
Native Formula compilation, Bake and source plugins require Apple's Command Line
Tools or Xcode. Ordinary formulas retain their interpreter fallback. Microphone
and system/application capture require the corresponding permissions. Device
selections saved on another operating system need changing; Windows ASIO drivers
are not used on macOS.

## Help test

Please try playback, recording, device switching, MIDI/Learn, Formula/Bake,
capture permissions, Finder file opening and display scaling. Report your Mac
model, macOS version, audio device and steps to reproduce problems.
`Check-Mac.command` inside the DMG collects diagnostics under
`~/Library/Logs/EasyKnack`; compiler checks require the Apple tools above.
