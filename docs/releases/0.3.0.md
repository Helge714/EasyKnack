EasyKnack 0.3.0 expands Formula programming, improves instrument envelopes and makes documentation easier to use.

## What's new

- **More powerful formulas:** define your own functions, use bounded loops and write clearer code with final/const variables. Completion, error messages and function help are improved.
- **Searchable help:** search the current documentation page and jump directly to function descriptions. German and English language references are included.
- **Better instruments:** separate Attack/Decay/Release controls, selectable retrigger behavior and MIDI release tails. Eligible Instance Group Bakes render faster and show their progress.
- **Smoother workflows:** edit recording names directly, keep graph layouts compact and retain the correct port types when grouping.
- **More accurate Sine Cloud control:** configurable frequency resolution and corrected period reporting.

## Opening existing projects

Keep a copy of important projects before saving them with the new version. Review Envelope timing and Sine Cloud settings: their behavior has changed. Use **Gate** for MIDI note on/off control; Frequency and Velocity now remain available during release tails. Formula variables or functions called final, const or root need another name.

## Download and install

1. Download **[EasyKnack-Setup-0.3.0-x64.exe](https://github.com/Helge714/EasyKnack/releases/download/v0.3.0/EasyKnack-Setup-0.3.0-x64.exe)**.
2. Run the downloaded file and follow the setup instructions.

Requires **64-bit Windows** and a **64-bit Java 25 JDK**. Setup checks Java and helps you set it up if it is missing.

**The setup EXE is the only download needed for installation.** The other downloads contain source code, checksums and optional technical information.
