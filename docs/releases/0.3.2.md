EasyKnack 0.3.2 restores visual improvements that were missing from 0.3.1.

## Improvements

- **Consistent node colors:** Delay is displayed as an Audio node. Buffer nodes and signals use Audio colors again.
- **Clearer Formula highlighting:** variables share one color; bold and italic styling still distinguish their qualifiers.
- **More readable analysis curves:** stronger contrast and thicker lines in dark and light themes.
- **Complete examples:** the installer checks all sixteen example projects and both language guides before packaging.

## Download and install

Download **[EasyKnack-Setup-0.3.2-x64.exe](https://github.com/Helge714/EasyKnack/releases/download/v0.3.2/EasyKnack-Setup-0.3.2-x64.exe)** and follow the setup instructions. This is the only download needed for installation; examples are included.

Requires **64-bit Windows** and a **64-bit Java 25 JDK**. Setup checks Java and helps install it if needed. The installer is unsigned, so Windows may ask you to allow it explicitly.

Existing 0.3.x projects remain compatible; audio processing is unchanged. Linux and macOS builds remain separate experimental downloads.

The other downloads provide source code and checksums.
