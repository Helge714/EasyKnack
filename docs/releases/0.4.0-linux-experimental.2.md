**Experimental Linux test build — not a stable release.**

This complete package replaces Linux test 1; no separate patch is needed. It fixes
the renderer-cache error reported at startup and when moving between displays,
and improves native compiler diagnostics. The fix passes local GPU regressions;
real Linux monitor transitions still need testing.

Audio routing, system/application capture and virtual MIDI checks passed on an
EndeavourOS test computer. Its separate Formula acceptance failure remains under
investigation; this build reports the failed command and exit code more clearly.
The program remains experimental.

## Download and start

1. Download **`EasyKnack-0.4.0-SNAPSHOT-linux-x86_64-test-2.tar.gz`** below.
2. Extract the complete archive into a writable local folder.
3. Open a terminal in the extracted `EasyKnack` folder and run `./Check-Linux.sh`.
   The first compiler check can take several minutes.
4. Run `./Start-EasyKnack.sh` and select your Linux audio/MIDI devices.

This is a **portable archive, not an installer**. The `.tar.gz` is the only
required download. Source archives and review files are for redistribution and
inspection; checksums are optional integrity checks. Keep copies of important
projects before saving them with this development build.

## Included

- Sixteen example projects with German and English instructions.
- Bundled Java JDK and C++ compiler for Formula, Bake and source plugins; no
  separate Java/compiler installation is needed.
- Linux implementations for multiple audio devices, system/application capture,
  hardware MIDI and MP3 recording.
- License notices and matching source/build materials.

## Requirements

Linux **x86_64 (Intel/AMD)** with glibc 2.28 or newer, X11/XWayland and OpenGL 3.
ARM and Alpine/musl are not supported by this package. Desktop audio features
require PulseAudio or PipeWire-Pulse; hardware MIDI requires ALSA. Device
selections saved on another operating system need changing; Windows ASIO drivers
are not used on Linux.

## Help test

Please try startup, playback, recording, device switching, MIDI/Learn,
Formula/Bake, system/application capture and display scaling. Report your Linux
distribution, audio device and steps to reproduce problems, and share the
`linux-diagnostics.txt` generated by `Check-Linux.sh`.
