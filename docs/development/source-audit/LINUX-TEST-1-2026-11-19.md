# Linux experimental test 1: distribution review

Scope: `v0.4.0-linux-experimental.1`, archive
`EasyKnack-0.4.0-SNAPSHOT-linux-x86_64-test.tar.gz`, SHA256
`72de7a58cdb281891f9924b74d2d2e6c93967b631c0887202a5be87f3b231a63`.
This is a technical license/source review, not legal clearance or a Linux execution test.

## Findings and remediation

The original archive contains 18,601 regular files/links, including 43 supplemental
license files, the complete upstream JDK legal tree and compiler notices. Its JDK
and Zig payloads match the exact official archives file for file, including links.
The extra compiler wrapper is EasyKnack code. The source snapshot hashes verify.

Two source-distribution weaknesses were found and addressed with the matching
`EasyKnack-Linux-test-1-license-materials.zip` release asset:

- The exact Temurin build scripts/configuration were not included. The supplement
  supplies build commit `8d9fd6fa96e5066571a13823b07c2934e5958d8b`, official build
  metadata, configure/make arguments and the upstream SBOM. The matching full
  OpenJDK source archive is already inside the binary distribution, under `sources`.
- The existing local GLSwing build-input ZIP was stale for two files. Reconcile it
  with the exact shipped source JAR and build an isolated copy. All 967 runtime
  classes and other runtime resources match. Differences are limited to generated
  build identity and Maven POM metadata; byte-identical JAR reproduction is not
  claimed. The corrected build inputs and comparison evidence are supplied.

The Loris integration already identified its local changes; dated notices have
also been added directly to its two modified headers. PulseAudio's instantiated
version header now has a dated modification notice. The supplement includes an
updated complete project source snapshot with these comment-only corrections,
plus the original full LAME release source. Executable code and the published
binary archive are unchanged. Original source snapshot hashes remain independently
available inside that archive; the supplement identifies its notice-only changes.

JOGL's comprehensive notice mentions optional Oculus support and other components;
this does not mean those binaries are shipped. Historical Windows/WiX/compiler
notices may also appear in the supplemental notices directory. No Windows installer,
LLVM-MinGW compiler, ASIO driver binary or Microsoft VC/UCRT runtime is shipped in
this Linux archive. ASIO SDK source headers retain their GPLv3 alternative in the
source snapshot; that does not make them Linux runtime dependencies.

## Recipient instructions and continued obligations

Keep the binary archive and matching source/license-materials download publicly
accessible together, without an extra source fee or different access restrictions.
The original full OpenJDK source archive lives inside the binary archive; recipients
can extract it without starting EasyKnack. The separate supplement completes the
build evidence and adds dated source notices. Retain both assets for this release.

LAME can be replaced by an ABI-compatible build of `libmp3lame.so.0` at
`EasyKnack/native/libmp3lame.so.0`; the launcher adds that directory to the dynamic
library search path. There is no signature check or restriction on debugging or
reverse engineering modifications. Build recipes are in the project snapshot's
native CMake files and cross-build script; source changes and relinking are allowed
under the applicable licenses. The application remains GPLv3.

Do not treat an experimental label, passing hash checks or an included license file
as a waiver of license obligations. Future changed binaries require fresh source,
notice and dependency review; do not overwrite released assets with new bytes.

## Verification and limits

`scripts/audit-linux-licenses.py` verifies the immutable archive against the exact
upstream JDK/compiler archives, required notices, project source snapshot, reconciled
Core sources and rebuilt runtime. The supplement's `linux-license-evidence.json`
records file hashes, JAR contents, source/build references and checks. Linux native
JAR provenance, JDK metadata/SBOM and the Core rebuild log are also retained.

No unresolved technical source/notice gap was identified in the reviewed scope after
these additions. This does not certify third-party authorship, patent freedom,
trademark/design clearance, every historical Git revision or legal enforceability.
The Blender-style/overall-appearance question remains separate; no lawyer or upstream
rights holder was contacted. A binding assessment requires qualified legal review.
