# Tabellen der Node-Referenz

<a id="name"></a>
## Bezeichnung

Name des Ports oder Parameters. Deutsche Referenzen nennen den deutschen Namen
und anschließend den englischen Namen in Klammern.

<a id="editor-range"></a>
## Reglerbereich

Werte oder Auswahlmöglichkeiten, die sich im Editor manuell einstellen lassen.
Die Grenzen gelten nicht automatisch auch für ein verbundenes Signal.

<a id="signal-range"></a>
## Signalbereich

Der für die Verarbeitung verwendete Bereich verbundener Werte. Zusätze wie
„abgerundet“ beschreiben die Behandlung des Eingangswerts. Es gelten die
Begrenzungs-, Rundungs- oder Wrap-Regeln des jeweiligen Nodes.

<a id="default"></a>
## Standardwert

Anfangswert eines neu angelegten Nodes. Ein im Dokument gespeicherter Wert kann
davon abweichen.

<a id="range"></a>
## Wertebereich

Wertebereich des Ausgangs. `±1` steht für −1 bis +1. `±∞` bezeichnet einen
unbeschränkten Bereich endlicher reeller Zahlen, nicht gültige Unendlich-/NaN-Werte.

<a id="visibility"></a>
## Sichtbarkeit

Bedingung, unter der ein Parameter im Node angezeigt wird. „Immer“ bedeutet,
dass keine zusätzliche modusspezifische Bedingung besteht; allgemeine Funktionen
wie Hide und das Ausblenden verbundener Editoren gelten weiterhin.

<a id="input-output"></a>
## Eingang und Ausgang bei Mute und Einfügen

Die angegebenen Namen bezeichnen das verwendete Portpaar. `—` steht für keine
Zuordnung oder eine nicht anwendbare Angabe. Die
[Mute-Tabelle](muting.md) unterscheidet zusätzlich, ob Mute unterstützt wird.

Datentyp, Einheit, Rate und Kanal sind unter [Datentypen](data-types.md),
[Einheiten](units.md) und [Raten](rates.md) erklärt.
