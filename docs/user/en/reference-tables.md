# Node reference tables

<a id="name"></a>
## Name

Name of the port or parameter. German references give its German name followed
by the English name in parentheses.

<a id="editor-range"></a>
## Editor range

Values or choices available for manual editing. These limits do not automatically
constrain connected signals.

<a id="signal-range"></a>
## Signal range

Range used when processing connected values. Qualifiers such as “rounded down”
describe input handling. The node's clamping, rounding or wrapping rules apply.

<a id="default"></a>
## Default

Initial value of a newly created node. A value saved in a document can differ.

<a id="range"></a>
## Range

Output value range. `±1` denotes −1 to +1. `±∞` denotes an unrestricted range of
finite real numbers, not valid infinity or NaN values.

<a id="visibility"></a>
## Visibility

Condition under which a parameter is shown in the node. “Always” means there is
no additional mode-specific condition; general Hide behavior and hiding connected
editors still apply.

<a id="input-output"></a>
## Input and output for Mute and insertion

Names identify the port pair used. `—` denotes no mapping or an inapplicable
entry. The [Mute table](muting.md) also states whether Mute is supported.

Data type, unit, rate and channel are explained under [Data types](data-types.md),
[Units](units.md) and [Rates](rates.md).
