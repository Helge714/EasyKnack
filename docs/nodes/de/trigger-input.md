## Bedienung
| Parameter | Einstellung | Signal / Bedingung |
| --- | --- | --- |
| Trigger | Button | Trigger |

## Ausgänge
| Ausgang | Signal |
| --- | --- |
| Trigger | Trigger |

## Verhalten
Jeder Druck plant ein Ereignis zum nächsten Audioblock. Ein aufgefächerter Ausgang kann mehrere Nodes am selben Sample zurücksetzen.

## Routing
| Funktion | Verhalten |
| --- | --- |
| Mute | Kein Bypass |
