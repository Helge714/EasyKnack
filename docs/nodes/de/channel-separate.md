# Kanäle trennen (Channel Separate)
Trennt die beiden Kanäle eines Signals.

## Bedienung
| Parameter | Einstellung | Signal / Bedingung |
| --- | --- | --- |
| Stereoeingang (Stereo In) | — | Audio; ±∞; Audio |

## Ausgänge
| Ausgang | Signal |
| --- | --- |
| Links (Left) | Audio; ±∞; Mono |
| Rechts (Right) | Audio; ±∞; Mono |

## Verhalten

[Anleitung](../../user/de/channels.md)
Left und Right geben die jeweilige Quellseite als Mono aus, identisch auf beiden Zielseiten. Ein Monoeingang erscheint an beiden Ausgängen. Stimmengruppen bleiben erhalten.

## Routing
| Funktion | Verhalten |
| --- | --- |
| Mute | Kein Bypass |
