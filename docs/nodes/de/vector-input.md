# Vektoreingang (Vector Input)
Stellt einen editierbaren Vektor mit drei Komponenten bereit.

<a id="eingange"></a>
<a id="mute"></a>
<a id="einfugen"></a>

## Bedienung
| Parameter | Einstellung | Signal / Bedingung |
| --- | --- | --- |
| Position | ±∞ je Komponente; Standard: (0, 0, 0) m; m, km, cm, mm; °, rad, turn; ×, % | Vektor |
| Größe (Quantity) | Länge, Winkel, Skalierung, Einheitenlos; Standard: Länge | Editor; Inspektor |
| Rate | Auto, Audio, Control; Standard: Auto | Editor; Inspektor |

## Ausgänge
| Ausgang | Signal |
| --- | --- |
| Vektor (Vector) | Vektor; ±∞ je Komponente |

## Verhalten
Quantity legt Interpretation und erlaubte Komponenteneinheiten fest; eine verbundene Vektorquelle wählt sie nicht automatisch.

## Routing
| Funktion | Verhalten |
| --- | --- |
| Mute | Kein Bypass |
